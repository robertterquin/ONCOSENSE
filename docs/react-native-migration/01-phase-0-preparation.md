## Risks

| Risk | Mitigation |
|---|---|
| Rotating the key breaks news in installed Flutter builds | Ship the Flutter `news`-function change first, then revoke the old key |
| Dev and prod schemas drift | Every schema change goes into `supabase/` SQL and is applied to both |
